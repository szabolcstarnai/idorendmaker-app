# Catalog Update Guide

How to update the race catalog when official race data changes.

## Pipeline

1. **Download raw race data** from the official source (manual step).

2. **Deduplicate the export:**
   ```bash
   python ../idorendmaker-scripts/dedupe_ablak_export.py <raw_export.xlsx>
   ```
   This produces `deduped_with_counts.xlsx`.

3. **Replace the source Excel:** rename `deduped_with_counts.xlsx` to `versenyszamok.xlsx` and move it to `documents/versenyszamok.xlsx`.

4. **Update boat class metadata** if boat classes changed: edit `documents/Hajoosztaly_Hajoosztaly-tipus_Hajoosztaly-ulesszam.txt` (tab-separated: name, boat type, seat count text).

5. **Generate the seed catalog:**
   ```bash
   cd idorendmaker-db-populator
   npm run populate:seed
   ```
   This writes `seed-catalog.db` to `idorendmaker-backend/src/main/resources/db/seed-catalog.db`.

6. **Boot the app and verify:**
   ```bash
   cd idorendmaker-backend
   ../mvnw spring-boot:run
   ```
   Check API endpoints to confirm data is correct.

7. **Commit and ship** the updated `seed-catalog.db` along with the new source files.

## Notes

- The populator always creates the database from scratch (deletes any existing file first).
- String codes are generated by slugifying Hungarian names (e.g., "K-1 Ferfi Felnott 1000 m" becomes `k-1-ferfi-felnott-1000-m`).
- Race `sort_order` is derived from occurrence count in the Excel (most common races get lowest sort_order values).
- The `catalog_version` in `catalog_meta` should be updated in `populate-db.ts` when making significant data changes.
